# Linux System Administration — TechNet Solutions Internship Simulation

### Scenario
Simulated an IT internship at TechNet Solutions, a small company running Linux servers and workstations, covering file system management, task automation, user/access administration, and network troubleshooting.

### What I did

**File system navigation & management**
- Documented the purpose of core Linux directories (`/home`, `/etc`, `/var`, `/bin`, `/usr`) as part of a system audit
- Practised file system operations: creating directories and files, displaying file contents, moving and deleting files, and resolving absolute paths

**Automation with shell scripting**
- Wrote `backup.sh`, a shell script that automates the company's daily configuration backup: creates a backup directory, copies all `.conf` files from `/etc`, prints a completion message, and includes explanatory comments throughout
- Made the script executable and documented the execution process, replacing what had been a manual, error-prone hour-long daily task

**User, group & permissions administration**
- Onboarded a new developer account: created the user and a `staff` group, assigned group membership, created a file with correct ownership (`user:group`), and restricted permissions so only the owner could read/write
- Applied `chmod`, `chown`, and `chgrp` to manage file permissions and ownership

**Network & performance troubleshooting**
- Diagnosed connectivity issues using connectivity tests, interface inspection, active connection/listening port checks, route tracing, and DNS lookups
- Investigated system performance: checked disk space, identified top memory-consuming processes, and installed/removed a package via the system's package manager

### Skills demonstrated
`Linux file system administration` · `Bash/shell scripting` · `User & group management` · `File permissions (chmod/chown/chgrp)` · `Network diagnostics` · `Package management` · `System performance troubleshooting`
